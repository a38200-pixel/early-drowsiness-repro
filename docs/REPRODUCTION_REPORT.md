## 1. 배경과 목적과 방침

- **배경**: 논문의 baseline(HM-LSTM 기반 시간 모델)을 원저자 공개 코드로 UTA-RLDD에서 다시 돌려 보고, 어디까지 같은 값이 나오는지 기록한다. 영상→blink 특징→시퀀스→학습까지 전 과정을 재실행하는 것이 범위이다(2절). [확실]
- **방침**: 저자 코드에 충실하다. 원본 `.py` 6개와 공개 체크포인트·npy는 수정하지 않고(바이트 동일, 보호 목록 44개 파일; 문서 3절, `THIRD_PARTY.md`) 변경은 래퍼가 텍스트를 읽어 메모리에서만 치환한다(문서 3.1절). **튜닝 금지**: 하이퍼파라미터는 저자 값(epoch 80, batch 64, lr 0.000053, 4×32 층, L2 0.1, Δ=1.253; 문서 11절)을 쓰고 성능을 보고 바꾸지 않는다(로그 "영상 단위 진단 기준선 사전 등록 (2026-10-04)"). 보고값은 마지막 epoch(80)이며 최고 epoch 값은 낙관적 참고치이다(로그 "B1 기준선 학습 결과 집계 사전 등록 (2026-10-04)").
- **목적의 한계**: 이 보고서는 "재현했다/못 했다"를 판정하지 않고, 일치한 것과 일치하지 않은 것, 아직 모르는 것을 구분해 적는다. [확실]

## 6. 해석

**말할 수 있는 것**
- 공개 체크포인트 평가는 논문 표 14칸 중 11칸과 일치하고 3칸은 일치하지 않는다(원인 미확인). [확실] (5.1)
- 같은 입력·하이퍼파라미터로 재학습한 B0의 5-fold 평균 VA는 공개 체크포인트보다 낮다(0.556 대 0.649). 원인은 미검증이다. [확실] (5.2)
- B1은 정상성 점검을 통과했고, 재평가한 체크포인트가 마지막 epoch 지표와 일치한다. [확실] (5.3, 5.4)
- B1의 클래스 5 정확도는 세 시드 모두 클래스 0과 10보다 낮다. [확실] (5.4)
- 영상 요약 특징만으로 만든 단순 분류기도 다수 클래스 기준과 라벨을 섞은 대조보다 높다. [확실] (5.5)
- 이 표본(영상 167개)으로는 B1과 영상 진단 분류기, 시드 1과 시드 2의 VA 차이를 구분할 수 없다(ΔVA 구간이 0을 포함). [확실] (5.6)
- 저자 테스트 영상 174개 중 우리 영상과 값이 일치한 것은 피험자 2명(09는 비트 단위, 31은 근사)뿐이다. [확실] (로그 "정렬 없는 일치 탐색 결과 (2026-10-03)", "클래스별 풀링 통계와 단계적 일치(탐색적) 결과 (2026-10-03)")

**말할 수 없는 것**
- B1이 논문이나 저자 결과를 재현했는지(영상 집합과 추출 결과가 달라 같은 비교가 아님). 미확정
- B1 또는 B0와 공개 체크포인트의 격차의 원인(영상 구성, 추출, 정규화 기준, 시드, 환경). 미검증
- B1이 시간 구조를 학습했는지(영상 요약 특징만으로도 우연 수준보다 높다는 것까지만 안다). 미검증
- 저자가 어떤 영상을 제외했는지. 미확인
- 0을 포함하는 ΔVA 구간은 "차이가 없다"의 증거가 아니다. [가능성 높음]

## 8. 한계와 미확인

- **표본**: 영상 167개, 피험자 57명, fold당 32~35개. 영상 하나가 fold VA를 약 0.03 움직이고, 기준선 ΔVA 구간의 반폭이 0.075~0.085이다(5.6). 시드는 3개뿐이라 SD는 참고 수준이다.
- **비교의 한계**: B1과 B0·공개 체크포인트·논문은 영상 집합과 추출 결과가 달라 같은 비교가 아니다(P-15, P-23). 클래스 5 정확도는 우연 수준 근처이다(5.4, 5.5).
- **미확인**: 저자가 제외한 영상, 공개 체크포인트의 선택 이력, 격차의 원인, 체크포인트 안의 epoch 번호(문서 13절).
- **논문 원문 대조가 필요한 항목**(논문 PDF는 저장소에 없고 근거가 작업 지시 또는 사용자 확인): 논문 Table 2·3 값(로그 step 6은 처음에 ar5iv 요약 값이라 PDF 대조가 필요하다고 적었다), 60명·영상 180개·fold당 36개, §3.2 품질 제외 서술, §5.2 하이퍼파라미터, Eq.1~13, Fig.2, P-08·P-09·P-10·P-13·P-15의 논문 서술(문서 2절, 8절).
- **추출 일치**: 저자 테스트 영상 174개 중 값이 일치한 영상은 피험자 2명뿐이다. 원인은 미검증이다(6절).
- **진단 특징**: 시퀀스 2개 이상이면서 `n_blinks_used`가 홀수인 영상 69개는 마지막 blink 1개가 영상 단위 진단 특징에서 빠졌다. B1 학습에는 영향이 없다(로그 "영상 단위 진단 기준선 사전 등록 (2026-10-04)").
- 개선 실험은 하지 않았다. 개선 실험의 규칙은 `EVALUATION_PROTOCOL.md`를 따른다.
