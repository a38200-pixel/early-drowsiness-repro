# 사전 기준 정리

README의 "기준을 실행 전에 정해" 또는 "사전 정한 기준"이 구체적으로 어떤 기준인지, 결과가 어땠는지, 나중에 바뀐 것이 있는지를 기존 기록에서 뽑아 정리한 문서입니다. **새로 해석하거나 추측한 내용은 없고**, 각 항목은 근거 문서의 문장과 git 커밋 시각을 옮겼습니다. 용어는 [REPRODUCTION_RESULTS.md](REPRODUCTION_RESULTS.md)의 용어 표를 따릅니다.

## 1. 한 줄 요약

사전 기준은 결과를 보기 전에 문서에 적어 커밋해 둔 판정 조건입니다(규칙 알람 실험 E-01과 E-02, 데모 임계값 선택 테스트, 점수 경로 대조의 허용 오차 등). 사전 기준이 아닌 것은 웹캠 실행의 처리 속도와 알람 대응 같은 관찰 기록입니다. 결과를 본 뒤 달라진 것은 2건(허용 오차 완화 1건, 사전 기준을 충족하지 못한 채 정한 임계값 0.15 1건)이고 3절에 있습니다. 이 문서는 활용 트랙(코드 폴더 improve)의 기준을 다루며, 재현 트랙의 사전 등록 항목은 [REPRODUCTION_LOG.md](REPRODUCTION_LOG.md)에 있고 여기서는 다루지 않습니다.

### 값은 바뀌지 않았으나 결과 뒤에 문서화된 것

- 열림과 감김 길이 정의(결정 I-17)의 명문화는 E-01 결과를 확인한 뒤에 이루어졌습니다. 기록에는 "코드는 E-01 실행 전부터 이 정의대로였고 결과를 보고 바꾸지 않았다"고 적혀 있습니다(로그 "정의 명문화와 영상 2개 등록 (2026-10-07)"의 일탈 항목).

위 두 표의 "커밋 전 수정"은 문서의 변경 이력과 로그가 그렇게 적은 것이며, 문서의 첫 커밋에는 최종본만 들어 있어서 중간 판은 git으로 확인할 수 없습니다.

**사전 기준이 없거나 기록에서 찾지 못한 것**

- 웹캠 실행(4회)의 처리 속도, 첫 점수가 나온 시각, 알람 대응(의도한 알람 시각은 기억 기반의 근사)에 대해 합격 기준을 정한 기록을 찾지 못했습니다. 값은 관찰로만 기록되어 있습니다.
- 데모 임계값 후보 0.15, 0.16, 0.17을 고른 것은 작성자의 웹캠 체험 판단이며 측정이 아니라고 기록되어 있습니다(결정 I-21). 선택 기준은 그 뒤에 만들어졌고 2절 3번이 그 결과입니다.
- E-02의 영상 1이 "3초 이상 감김 없음"이라는 것은 작성자 진술입니다(기록상 확인하지 않음).
- 3.0초 알람 기준은 사전 고정된 규칙 값입니다(결정 I-03, 결정 I-05). 실험에서 이 값의 위치를 시험하지 못했다고 기록되어 있습니다(E-02, 양성 사건이 모두 6초에서 7초 길이).

**순서 확인 방법.** 기준 문서나 기준을 적은 로그 항목의 git 커밋 시각과, 결과를 적은 항목의 커밋 시각 및 로그에 적힌 산출물 수정 시각을 비교했습니다. 확인된 순서는 다음과 같습니다.

- E-01: 기준 문서 커밋 2026-10-06 22:03, 추출 실행 2026-10-07 09:04(산출물 수정 시각이 커밋 뒤), 결과 커밋 2026-10-07 11:01.
- E-02: 기준 문서 커밋 2026-10-07 14:41, 회전 처리 코드 커밋 15:06, 산출물 수정 시각이 그 뒤, 결과 커밋 19:11.
- 임계값 선택 테스트: 계획 항목 커밋 2026-10-07 20:51, 결과 항목 커밋 21:34.
- 행 대조: 기준(소수 4자리) 커밋 2026-10-08 16:08, 결과 커밋 2026-10-09 16:00.
- 점수 허용 오차 1e-5와 행 4자리: 커밋 2026-10-09 16:38. 5개 폴드 결과 커밋 2026-10-10 12:52, 전체 경로 대조 결과 커밋 2026-10-11 16:57.

**순서 미확인.** 5개 폴드 대조의 창 값 허용 1e-9와 전체 경로 대조의 행 최대 차이 5e-5, 창 수 5와 56은 결과 항목과 같은 커밋에서 처음 나타납니다(로그는 "실행 전에 정함"이라고 적음). 실데이터 동치 검증의 Freq 열 1e-5는 작업 지시문에만 있었습니다. 세 도구(`ear_hook_compare`, `live_score_recheck`, `live_combined`)의 판정 조건은 코드에 있고 도구 커밋 시각과 결과 기록 커밋 시각의 간격이 4분에서 19분이라, 실행이 커밋 전이었는지 확인할 수 없습니다.
