# 데이터 등록부 (영상 2개)

작성일: 2026-10-07. 개선 트랙에서 쓸 영상 2개의 메타데이터와 영상 2의 대본 구간을 등록한다. 이 문서는 등록뿐이며 영상에 EAR 추출, 규칙, 일치 계산을 실행하지 않았다. 영상 내용은 열람하지 않았다(파일의 바이트와 컨테이너 메타데이터만 읽음). 확실도는 [확실], [가능성 높음], [추측]이고 확인하지 않은 것은 "미검증", 상태 단어는 "일치/불일치/미확정/미검증"만 쓴다. 영상 파일 경로는 `<VIDEO_DIR>`로만 쓴다.

- sha256은 Python `hashlib`로 파일 바이트 전체를 읽어 계산했고, 크기는 `os.path.getsize`이다. 파일은 수정하지 않았다. [확실] (측정)
- fps, 프레임 수, 가로, 세로는 `cv2.VideoCapture`의 속성 값이며 **메타데이터 값이라 실제 디코딩 값과 다를 수 있다(미검증)**. 프레임은 디코딩하거나 저장하지 않았다. 길이는 프레임 수 ÷ fps로 계산한 값이다. [확실] (측정과 산술)
- 사용자 진술: 영상 1은 "정상상태 5분짜리", 영상 2는 "대본영상"이다(사용자 진술, 2026-10-07).
