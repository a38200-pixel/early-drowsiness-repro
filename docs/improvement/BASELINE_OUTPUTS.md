## 2. 보관할 항목

### 2.1 영상별 예측 CSV (15개 체크포인트)

기존 도구 `src/repro/evaluate_baseline_checkpoints.py`가 시드별로 `video_predictions_seed<s>.csv`를 낸다. 그 파일의 열은 코드의 `PREDICTION_COLUMNS`(42줄)에서 읽은 `fold, video_id, true_class, pred_class, regression_mean`이다. [확실] (코드 읽기) 이 도구는 `subject_id`와 `seed` 열을 CSV에 쓰지 않는다(시드는 파일 이름에 있다). 클래스별 점수도 쓰지 않으며, 체크포인트에서 클래스별 점수를 얻을 수 있는지는 미검증이다.

보관 형식 제안(미확정):

| 열 | 내용 | 출처 |
|---|---|---|
| video_id | 영상 식별자 | 기존 열 그대로 |
| subject_id | 피험자 번호 | 기존 CSV에 없음. video_id 경로의 중간 숫자에서 얻을 수 있을 것으로 보이나 미검증 |
| fold | 1~5 | 기존 열 그대로 |
| seed | 시드 번호 | 기존 CSV에 없음(파일 이름에서 얻음) |
| true_label | 실제 클래스(0, 5, 10) | 기존 `true_class`를 같은 값으로 옮김 |
| pred_label | 예측 클래스(0, 5, 10) | 기존 `pred_class`를 같은 값으로 옮김 |
| regression_mean | 영상 평균 회귀 출력 | 기존 열 그대로(코드에 있는 열) |
| 클래스별 점수 | 가능하면 | 현재 산출 코드에는 없음. 가능 여부 미검증 |

### 2.2 대상 체크포인트 15개와 위치 규칙

5 fold × 3 시드 = 15개. 학습 러너 `src/repro/reproduction_train_baseline.py`가 정한 규칙은 다음과 같다(코드 읽기, 파일 내용은 열지 않았다). [확실] (코드 읽기)

| 항목 | 규칙 | 근거 |
|---|---|---|
| 출력 루트 | 환경변수 `TRAIN_OUT_DIR`(저장소 밖, 기본값 없음) | 12줄, 126-137줄 |
| 실행 폴더 | `<TRAIN_OUT_DIR>/<실행 이름>/`. 실행 이름의 기본값은 `seed<시드>`(스모크는 `smoke_seed<시드>`) | 70, 601줄 |
| fold 폴더 | `<실행 이름>/fold<k>/` (k = 1~5) | 504줄 |
| 체크포인트 | fold 폴더 안의 `my_model<k>.*` (TF 체크포인트 파일들) | 12줄, 20줄, 212줄(저장 경로 치환) |
| 같은 폴더의 기록 | `metrics.csv`, `final_metrics.json`, `run_config.json`, `train.log` 등 | 12-13줄 |

평가 도구는 학습 출력 **루트 하나에서 SMOKE가 아닌 완전한 실행 폴더(fold1~5) 하나**를 요구한다(`evaluate_baseline_checkpoints.py` 93줄). 따라서 시드 3개의 실행은 별도 루트(또는 평가 도구가 지정하는 루트 목록)로 나뉘어 있을 것이다. [가능성 높음] 실제 폴더 위치는 환경변수와 인자로만 받는 값이라 이 문서는 확인하지 않았다(미검증). 이 폴더들은 읽기 전용 입력이며 이 문서의 어떤 작업도 수정하지 않는다.
