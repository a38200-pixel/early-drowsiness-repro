## 읽기 전용 점검 결과 (작업 1, 1b, 1c)

- 저자 코드 `third_party/ghoddoosian/blink_video.py`(읽기만 함, 실행하지 않음): EAR = (A + B) / (2.0 × C), A = dist(eye[1], eye[5]), B = dist(eye[2], eye[4]), C = dist(eye[0], eye[3])(74-92줄). C < 0.1이면 0.3, EAR > 0.45이면 0.45(84-90줄). 양쪽 눈 평균(417-421줄). 눈 랜드마크 인덱스는 imutils 상수를 쓰며 이 환경에서 읽은 값은 왼쪽 (42, 48), 오른쪽 (36, 42). 전처리는 너비 450 리사이즈, 그레이스케일, 감마 1.5(359, 368, 370줄). 얼굴 미검출 프레임은 광학 흐름 추적(486-523줄). 13프레임 EAR 창과 SVM 분류(330, 423, 444줄). EMERGENCY 카운터는 `ear < 0.21`이 50프레임 이어지면 문구를 출력만 하고 카운터를 초기화한다(110-120줄). 프레임 번호가 아니라 타임스탬프를 쓰는지: `ElapsedTime`을 계산하지만(373줄) 파일 안에서 쓰이지 않고 판정은 프레임 수로 한다. [확실] (코드 읽기)
- 환경(읽기 전용 import 확인, 설치 시도 없음): `tkinter` 가능(tk ok), `PIL` 가능(Pillow 8.3.1), `cv2` 3.4.5. `PIL.ImageTk` 가능 여부와 웹캠 접근 가능 여부는 확인하지 않았다(미검증). [확실]
- B1 체크포인트 위치 규칙(코드 읽기): `<TRAIN_OUT_DIR>/<실행 이름>/fold<k>/my_model<k>.*`, 실행 이름의 기본값은 `seed<시드>`. 평가 도구는 학습 출력 루트마다 완전한 실행 폴더 하나(fold1~5)를 요구하므로 3시드는 별도 루트에 있을 것으로 보인다. [가능성 높음] 실제 폴더 위치는 미검증이다. 파일 내용은 열지 않았다.
