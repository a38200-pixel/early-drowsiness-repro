# 평가 프로토콜 (개선 실험용)

작성일: 2026-10-05. 이 문서는 **개선 실험을 실행하기 전에 고정하는 규칙**이며 결과를 본 뒤 바꾸지 않는다. 바꿔야 하면 맨 아래 "변경 이력"에 날짜 항목으로 이력을 남기고 이유를 쓴다. 이 문서의 모든 숫자에는 출처를 붙였다. 출처 표기: 로그 = `docs/REPRODUCTION_LOG.md`의 항목 제목과 날짜, 문서 = `docs/IMPLEMENTATION_DIFF.md`의 절 번호. 출처를 찾지 못한 숫자는 "미확인"으로 쓴다. 확실도 표기는 [확실], [가능성 높음], [추측]이고, 확인하지 못한 것은 "미검증", 논문에 명시되지 않은 수치는 "not explicitly reported"로 쓴다.

## 1. 목적과 범위

- 개선 실험은 **B1 기준선 대비 평가**이다. "저자 모델 대비 개선"이라는 표현은 쓰지 않는다. B0(저자 npy 기반 재학습과 공개 체크포인트), 논문 수치는 별도 열의 **참고치**로만 표기하고 개선 판정의 기준으로 쓰지 않는다. B1과 B0는 영상 집합과 추출 결과가 달라 같은 데이터셋이 아니다(7절, 10절 참조).
- 용어 정의
  - **B0**: 저자가 제공한 npy와 공개 체크포인트(`my_model1~5`)로 얻은 값, 그리고 저자 npy로 우리가 재학습한 값(시드 1~3). 논문 수치와 함께 참고치이다.
  - **B1**: 우리가 재추출한 blink txt에서 `reproduction_build_sequences.py`로 만든 시퀀스 산출물(영상 167개)로 `reproduction_train_baseline.py`(저자 `Training.py`를 메모리에서 치환, 하이퍼파라미터는 저자 값)를 시드 1, 2, 3으로 5-fold 학습한 결과. 개선 실험의 비교 기준(기준선)이다.
  - **실험 ID(E-xx)**: 개선 실험마다 로그에 사전 등록할 때 붙이는 번호(E-01, E-02, …). 실패하거나 중단한 실험도 번호를 소비한다.
- 영상 단위 진단(로지스틱, RF)은 **참조 대조군(재현이 아닌 한계 분석)**이며 개선 실험의 비교 대상이 아니라 "영상 요약 특징만으로 어디까지 가는가"를 보는 참고선이다.

## 2. 데이터

- 공식 5 fold(우리 start_indices와 메타데이터 기준)와 B1 영상 167개를 쓴다. 영상 167개, 피험자 57명이고(로그 "기준선 불확실성 추정 사전 등록 (2026-10-04)"), fold별 테스트 영상은 33, 33, 35, 32, 34개이다(로그 "degenerate_reference 정책 변경 결과와 정정 (2026-10-03)"). 인벤토리 182개 중 제외 15개: `variant_deferred` 4, `not_extracted` 8, `no_blink_file` 1, `no_alert_reference` 2(같은 로그 항목). 제외 목록은 문서 9.2절(제외 정책)과 같은 로그 항목을 참조한다. 이 제외는 "재추출 데이터에서의 기계적 결과"이며 저자가 어떤 영상을 제외했는지는 확인된 바 없다. [확실]
- 모든 실험은 **같은 영상 집합**을 쓴다. 부분집합을 쓰면 기준선(B1)도 같은 부분집합에서 다시 보고한다(새로 학습이 필요하면 별도 사전 등록).
- 같은 영상이 어떤 fold의 테스트에 한 번만 나오고 나머지 fold의 훈련에는 포함된다. 피험자는 하나의 fold에만 속한다(로그 "기준선 불확실성 추정 사전 등록 (2026-10-04)"의 1단계 점검). 훈련과 테스트가 피험자 단위로 분리되어 있다는 뜻이다. [확실]

## 3. 지표

- **주 지표**: 마지막 epoch(80)의 fold별 영상 단위 VA의 5-fold 평균을 시드 3개(1, 2, 3)로 평균한 값과 시드 간 표본 표준편차(n−1).
- **부 지표**: 클래스별 영상 정확도(특히 클래스 5), 5-fold 합산 3×3 혼동행렬, VRE. 최고 epoch 값은 테스트 세트로 고른 값이므로 "낙관적 참고치"로만 표기하고 주 결과로 쓰지 않는다.
- 통계적 비교(6절)에는 영상을 합산한 정답률을 쓴다. 주 지표(fold 평균)와는 fold 크기(32~35개) 때문에 소수 셋째 자리 안팎으로 다를 수 있다(B1 시드 평균: fold 평균 0.586 대 합산 0.5848; 로그 "B1 기준선 학습 결과 집계 (2026-10-04)", "기준선 불확실성 추정 결과 (2026-10-05)"). 두 값을 함께 적는다. [확실]

## 4. 모델 선택 규칙

- epoch 수와 하이퍼파라미터를 **테스트 fold로 고르지 않는다**.
- 튜닝이 필요하면 **훈련 피험자 안의 피험자 단위 검증 분할**에서만 한다. 선택 후 전체 훈련 데이터로 다시 학습한다. 튜닝 횟수(시도한 설정 수)는 기록한다.
- 최종 설정 하나당 테스트 fold는 시드별로 **한 번만** 평가한다. 평가 후 설정을 바꿔 다시 평가하는 것은 새 실험(새 E-xx)이다.
- B1 기준선의 하이퍼파라미터는 저자 값(80 epoch, batch 64, lr 0.000053, 4×32 층, L2 0.1, Δ=1.253)이며(문서 11절, 로그 "기준선 학습 러너(B1) 구현 사전 등록 (2026-10-03)") 개선 실험이 이를 바꾸면 그 변경은 개선 요인의 일부로 기록한다.

## 5. 시드

- 기준선과 같은 시드 1, 2, 3(문서 12절). 시드 3개의 평균 ± SD로 보고하되 **SD는 참고 수준**이다(n = 3). B1 시드 평균 5-fold VA의 SD는 0.015이다(로그 "B1 기준선 학습 결과 집계 (2026-10-04)").

## 6. 통계적 비교

- **짝지은 비교만** 쓴다(같은 영상, 같은 재표집). 피험자 단위 군집 부트스트랩(재표집 10000회, 난수 시드 0, percentile 95% 구간)으로 ΔVA(합산 정답률 차이)의 95% 구간을 낸다. 도구는 `src/repro/estimate_baseline_uncertainty.py`이고 방법과 한계는 문서 15절을 따른다.
- **판정 용어(고정)**
  - "**개선 확인**" = ΔVA 구간의 **하한이 0 초과**.
  - "**개선 경향(미검출)**" = ΔVA 점추정은 양수이나 구간이 0을 포함.
  - "**차이 없음/악화**" = 그 외.
  - 구간이 0을 포함하는 결과를 "개선"이라고 쓰지 않는다. 클래스 5 정확도 변화도 ΔAcc5와 95% 구간으로 병기한다.
- **기준선의 불확실성(측정값; 로그 "기준선 불확실성 추정 결과 (2026-10-05)")**

| 통계 | 점추정 | 95% 구간 | 반폭 |
|---|---|---|---|
| VA B1 시드1 | 0.5988 | [0.5269, 0.6687] | 0.0709 |
| VA B1 시드2 | 0.5868 | [0.5150, 0.6587] | 0.0719 |
| VA B1 시드3 | 0.5689 | [0.5060, 0.6272] | 0.0606 |
| VA B1 시드 평균 | 0.5848 | [0.5302, 0.6380] | 0.0539 |
| ΔVA B1 시드1 − 시드2 | +0.0120 | [−0.0610, 0.0893] | 0.0751 |
| ΔVA B1(시드 평균) − RF | +0.0279 | [−0.0575, 0.1118] | 0.0847 |
| ΔVA B1(시드 평균) − 로지스틱 | +0.0459 | [−0.0321, 0.1218] | 0.0769 |
| Acc5 B1 시드 평균 | 0.3274 | [0.2364, 0.4226] | 0.0931 |

- **검출 가능한 효과 크기**: 위 측정에서 ΔVA 구간의 반폭이 0.075~0.085이므로 같은 테스트 집합에서 구간 하한이 0을 넘으려면 점추정 차이가 대략 0.08~0.09 이상이어야 한다. 새 모델 대 B1의 구간 폭이 이번에 잰 쌍과 비슷하다는 가정에 의존하므로 [추측]이다. 미검증. ΔAcc5는 클래스 5 영상이 168개뿐이라 구간이 더 넓다(B1 시드 평균 Acc5의 반폭 0.0931).
- 이 구간은 표본 오차(같은 테스트 피험자 집합의 표집)만 잰다. 학습 난수의 변동은 시드 3개로만 일부 드러난다. 군집 부트스트랩의 percentile 구간이 충분히 보수적인지는 미검증이다.

## 8. 실험 등록 규칙

- 모든 실험은 **실행 전에** `docs/improvement/IMPROVEMENT_LOG.md`에 날짜와 함께 사전 등록한다: 실험 ID, 가설, 설정(바꾸는 것과 그대로인 것), 예측, 판정 기준(6절의 용어). 결과는 별도 날짜 항목으로 적고 적중 여부를 그대로 쓴다.
- 실패한 실험과 중단한 실험도 기록한다. 시도한 변형의 개수(튜닝 횟수 포함)는 최종 보고에 공개한다.
- 에이전트는 학습을 임의로 실행하지 않는다(실제 학습은 사용자가 한다). 열린 결정(9절)이 정해지기 전에는 실행하지 않는다.

## 10. 알려진 한계

- **표본 오차**: 영상 167개, 피험자 57명, fold당 32~35개라 영상 하나가 fold VA를 약 0.03 움직이고(로그 "B1 체크포인트 영상별 평가 결과 (2026-10-04)"), ΔVA 구간의 반폭이 0.075~0.085이다(6절).
- **클래스 5가 우연 수준 근처**: B1 클래스 5 정확도 0.327은 영상 168개 중 55개를 맞힌 값이고(7절), 다수 클래스 기준 VA 0.341과 가깝다(로그 "영상 단위 진단 기준선 결과 (2026-10-04)"). 클래스 5 정답 168개 중 77개가 클래스 10으로 예측되었다(7절).
- **최고 epoch 선택의 낙관 편향**: 최고 epoch 값은 80개 epoch 중 테스트 세트로 고른 값이므로 일반화 성능의 근거가 아니다.
- **추출 결과가 저자 npy와 영상 단위로 거의 일치하지 않음**: 저자 테스트 영상 174개 중 우리 영상과 값이 일치한 것은 피험자 2명(09는 비트 단위, 31은 근사)뿐이다(로그 "정렬 없는 일치 탐색 결과 (2026-10-03)", "클래스별 풀링 통계와 단계적 일치(탐색적) 결과 (2026-10-03)", 문서 10.5절, 10.7절). 원인은 미검증이다.
- **영상 69개에서 마지막 blink 미복원(영상 단위 진단 특징에 한정)**: 시퀀스 2개 이상이면서 `n_blinks_used`가 홀수인 영상 69개는 마지막 blink 1개가 진단 특징에서 빠졌다(로그 "영상 단위 진단 기준선 사전 등록 (2026-10-04)"). B1 학습 자체에는 영향이 없다. 진단 결과에 주는 영향의 크기는 미검증이다.
- **체크포인트 평가**: 체크포인트가 마지막 epoch의 가중치라는 점은 지표 일치(15개 fold)로 뒷받침되지만 파일 안에 epoch 번호가 없다(문서 13절). 미검증.
